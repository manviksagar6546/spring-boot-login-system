# spring-boot-login-system
Spring Boot application implementing a basic authentication system using Spring Security. Includes login functionality with form-based authentication, user validation, and secured endpoints. Built for learning and demonstrating Spring Security fundamentals.

# Spring Boot Login System

## Overview
This project is a basic authentication system built using Spring Boot and Spring Security. It demonstrates form-based login with user authentication.

## Features
- Spring Security integration
- Form-based login
- User authentication
- Protected endpoints
- Custom login page support

## Tech Stack
- Java
- Spring Boot
- Spring Security
- Maven

## How to Run
1. Clone the repository
2. Import into IntelliJ / Eclipse
3. Configure application properties if needed
4. Run the application
5. Open: http://localhost:8080/login

## Default Flow
- User visits secured page
- Redirected to login page
- Authentication required to access protected routes
